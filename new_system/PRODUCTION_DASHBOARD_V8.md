# Offline production dashboard v8

Built a standalone HTML dashboard for five draft stories and 80 scenes. Each scene shows exact Greek narration and its visual prompt. Review checkboxes separately track image, audio and visual QA; browser-local persistence plus JSON import/export. Dashboard is distributed as a local conversation artifact, not hosted or deployed. Validation: 5 stories, 80 scenes, HTML parsed. This does not generate images or audio, verify source files, connect to Metricool, or publish.
